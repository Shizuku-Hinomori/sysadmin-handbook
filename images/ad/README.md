# Galerie Active Directory — 48 captures

Ces **48 captures d'écran** proviennent du document de manipulation AD fourni par l'auteur et couvrent aussi les actions simples (réinitialisation, activation, groupes, profils, jonction au domaine, DNS, etc.). La 49e image, un fond de page ADRAR, n'est pas une capture de manipulation et a été exclue.

**Statut :** les 48 fichiers PNG sont présents dans `images/ad/` et les images sont affichées directement dans les fiches, sans sections à déplier.

**Avant de rendre le dépôt public :** relire les captures et masquer tout nom de personne, IP réelle, nom d'entreprise ou autre donnée privée si nécessaire. Plusieurs captures utilisent un nom d'utilisateur et un domaine de TP qui restent visibles.
